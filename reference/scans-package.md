# scans: Diagnose AI Agent Trajectories

An evaluation can show whether an AI agent succeeded. `scans` helps
explain the path that produced that outcome. It normalizes completed
runs from ellmer and related R packages, identifies evidence-linked tool
and error patterns, summarizes execution and usage, and provides a
read-only application for investigating the relevant turns and events.

## Details

`scans` is post-run and read-only. It does not execute agents, replay
tools, or score answer quality.
