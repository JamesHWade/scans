# Getting help with scans

Thanks for using scans.

## Questions

For help using the package or discussing agent-evaluation approaches,
start with a focused question and enough context to reproduce what you
are seeing. The [Posit Community](https://forum.posit.co/) and Stack
Overflow are useful for general R questions.

## Bugs and feature requests

Use the [scans issue
tracker](https://github.com/JamesHWade/scans/issues) for reproducible
bugs and concrete feature proposals. Search existing issues first to
avoid duplicates.

Please include:

- a minimal [reprex](https://reprex.tidyverse.org/), when applicable;
- the installed versions of scans and relevant integration packages;
- the expected and observed behavior; and
- sanitized trajectory data or a synthetic example that reproduces the
  issue.

Never include API keys, credentials, private prompts, or sensitive
trajectory content in an issue.

Maintainers may ask for more information before an issue is ready for
implementation. A focused reproduction makes it much easier to confirm
the behavior, design a fix, and add a regression test.
